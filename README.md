# Calculadora de Frete

Programa em Python que calcula o valor do frete de acordo com o peso e a região.

## Como usar
1. Execute `python calculo_de_frete.py`
2. Digite o peso e a região quando o programa pedir

## O que pratiquei
- Entrada de dados com `input`
- Estruturas condicionais (`if/elif/else`)
- Cálculos e formatação de valores
